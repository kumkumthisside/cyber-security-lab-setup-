# 🔐 Cybersecurity Lab Environment

A personal cybersecurity lab built using **Kali Linux** and **Oracle VirtualBox** for learning networking, Linux administration, reconnaissance, and ethical cybersecurity testing.

---

## 📌 Project Overview

This project documents the setup of an isolated virtual cybersecurity laboratory.

The lab uses Kali Linux running inside Oracle VirtualBox. The environment is configured to provide a controlled space for learning cybersecurity concepts and practicing security tools.

> ⚠️ All security testing in this project is performed only in authorized lab environments.

- 🛡️ Cybersecurity Tools
- 🐙 Git & GitHub
